Mini Git Project Dashboard

Projet réalisé dans le cadre du module Gestion de projet

Membres du projet

  • Negin Bagheri
  • Alex Martin, membre fictif

Objectif du projet

Ce projet a pour objectif de mettre en pratique les outils de gestion de projet avec Git et GitHub : dépôt en ligne, branches, pull requests, issues, milestones, GitHub Pages, tags et submodules.

Outils utilisés

GitHub Git GitHub Pages Issues Milestones Projects Submodule

État du projet

  • Dépôt GitHub créé
  • Site web publié en ligne
  • Gestion des tâches avec issues et milestone
  • Tableau de suivi créé avec GitHub Projects
